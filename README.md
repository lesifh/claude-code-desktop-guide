# Claude Code 桌面上手指南

面向个人使用的 Windows 11 中文图文式操作指南：通过一键部署工具安装 Claude Code 和 CC Switch，接入 DeepSeek，再使用 AionUi 独立桌面界面完成任务。

作者：[lesifh](https://github.com/lesifh)

## 如何阅读

- 下载本项目后，双击 `index.html` 即可离线阅读，无需安装依赖。
- 页面提供章节导航、代码复制、保存在当前浏览器中的验收清单，以及打印 / 存为 PDF 功能。
- 纯静态网页，可直接部署到任意静态网站服务，也可使用 GitHub Pages。

## 使用范围

适用 Windows 11 Intel / AMD x64。指南依据 2026 年 10 月 30 日可查的项目资料整理，尚未完成完整实机安装验证。版本和界面可能变化；模型参数请以 [DeepSeek 官方接入指南](https://api-docs.deepseek.com/guides/coding_agents/)为准。AionUi 连接 Claude Code 和第三方模型时，请先完成指南中的逐层验收。

## 隐私

页面无需填写 API Key，不包含上传或统计服务。验收勾选仅保存在当前浏览器本地。API Key 仅在本机的相应工具中配置。
